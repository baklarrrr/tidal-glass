# Tidal Glass

<sub>BAKAR STUDIO / PERSONAL EXPERIMENT</sub>

A wearable companion interface for phone-based music playback.

## Status

Experimental. This public repository contains the web interface. Connected playback and controls require the separate phone companion and the official TIDAL app on the paired phone. Device behavior is not fully verified.

[Project page](https://baklarrrr.github.io/tidal-glass/) | [Bakar Studio](https://bakar.ca/)
